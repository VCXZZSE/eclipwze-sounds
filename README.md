# Eclipwze Sounds website

Static website source and assets, ready to commit to GitHub or deploy as a static site on Vercel.

## Preview locally

Open `index.html` in a browser. For best results, serve this folder with a local web server so all relative assets load correctly.

## Main files

- `index.html` — homepage
- `style.css`, `theme.css`, `mobile.css`, `phone.css`, and section CSS files — styling
- JavaScript files — interactions, animations, content, and responsive behavior
- `assets/` — images, fonts, and icons
- `journal*.html` — journal articles
- `wix-move-landing/` — separate redirect landing page prepared for the old Wix site

No `node_modules` or build step is required for the static source.
